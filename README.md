# CFRobustness-of-Trees

A comprehensive framework for benchmarking the **robustness of counterfactual explanations** generated by tree-based classifiers. The framework systematically measures how counterfactual explanations degrade under data and model perturbations, providing insights into explanation stability and reliability.

## Overview

Counterfactual explanations answer: *"What is the smallest change to my features that would flip the model's decision?"* While many methods exist to generate these explanations, their **robustness**---whether they remain valid when the model is retrained on slightly different data or with different hyperparameters---is underexplored.

This framework evaluates **6 counterfactual methods** across **4 datasets** under systematic **data and model perturbations**, using 5-fold cross-validation.

## Counterfactual Methods

| Method | Description | Model Support |
|--------|-------------|---------------|
| **DiCE** | Diverse Counterfactual Explanations using gradient-based and random search | RF, XGB, LGB, MLP, AdaBoost |
| **CEML** | Contrastive Explanations via optimisation-based counterfactual generation | RF |
| **CFXplorer** | Counterfactual explorer for tree-based models using decision paths | RF |
| **NICE** | Nearest Instance Counterfactual Explanations using nearest neighbour search | RF, XGB, LGB |
| **FeatureTweak** | Generates counterfactuals by tweaking features along decision tree paths | RF |
| **CERTS** | Counterfactual Explanations via Robust Tree-Search using MCTS and perturbation ensemble validation | RF |

## Datasets

| Dataset | Features | Type | Label |
|---------|----------|------|-------|
| **Spambase** | 57 | Continuous only | Spam classification |
| **German Credit** | 9 | Mixed (categorical + continuous) | Credit risk |
| **HELOC** | 23 | Continuous only | Home equity line of credit risk |
| **COMPAS** | 6 | Mixed (with protected attributes) | Recidivism prediction |

All datasets are stored in `data/` as CSV files with two metadata rows (feature types and feature actions) followed by data rows.

## Experimental Protocol

Each experiment script follows the same two-stage protocol:

### 1. Baseline Counterfactual Generation

- Train a baseline Random Forest (max_depth=5, n_estimators=100) on the training fold
- Generate counterfactuals for all test instances using the CF method
- Record baseline metrics: success rate, validity, L2 distance, L0 distance, LOF score

### 2. Robustness Evaluation

**Data Perturbations** --- Test baseline counterfactuals against models trained on perturbed data:

| Perturbation Type | Levels |
|-------------------|--------|
| Minor deletion | 0%, 5%, 10%, 15%, 20% of training data removed |
| Major deletion | 0%, 50% of training data removed |
| Minor addition | 50%, 55%, ..., 100% of training data used |
| Major addition | 50%, 100% of training data used |

**Model Perturbations** --- Test baseline counterfactuals against different model configurations:

- Random Forest: max_depth in {3, 4, 5, 6}, n_estimators in {50, 100, 150, 200}
- Decision Tree: max_depth in {3, 4, 5, 6}

### Evaluation Metrics

| Metric | Description |
|--------|-------------|
| **Validity** | Fraction of counterfactuals that still flip the prediction under the perturbed model |
| **L2 Distance** | Average Euclidean distance between counterfactuals and originals |
| **L0 Distance** | Average number of features changed |
| **LOF Score** | Local Outlier Factor measuring whether counterfactuals lie within the data manifold |

## CERTS Method

**CERTS** (Counterfactual Explanations via Robust Tree-Search) is a novel counterfactual method that prioritises robustness. It differs from existing methods by:

1. **MCTS-based candidate generation**: Uses Monte Carlo Tree Search on each decision tree in the Random Forest to efficiently explore the constraint space, avoiding combinatorial path enumeration.

2. **Perturbation ensemble validation**: Validates candidates against an ensemble of models trained on perturbed data with varied hyperparameters, ensuring empirical robustness.

3. **Multi-objective scoring**: Ranks candidates by a composite score balancing:
   - Consensus (ensemble agreement, weight=0.4)
   - Margin (prediction confidence, weight=0.3)
   - Proximity (HEOM distance, weight=0.2)
   - Sparsity (number of features changed, weight=0.1)

4. **Feature actionability**: Respects immutable features (e.g., race, sex) by constraining the MCTS to follow branches consistent with the original values.

See `CERTS/CERTS_Methodology.tex` for the complete mathematical formulation.

## Usage

### Setup

```bash
conda activate cf-robustness
```

### Run All Experiments

```bash
python run_all_experiments.py
```

### Run a Specific Method on a Specific Dataset

```bash
# Method choices: DiCE, CEML, cfxplorer, NICE, feature_tweak, CERTS
# Dataset choices: v2 (Spambase), v3 (German-Credit), v4_heloc (HELOC), v5_compas (COMPAS)

python run_all_experiments.py --methods CERTS --datasets v3
```

### Run a Single Experiment Script Directly

```bash
cd CERTS
python cf_robustness_analysis_certs_v2.py   # Spambase
python cf_robustness_analysis_certs_v3.py   # German Credit
python cf_robustness_analysis_certs_v4_heloc.py  # HELOC
python cf_robustness_analysis_certs_v5_compas.py # COMPAS
```

### List Available Experiments

```bash
python run_all_experiments.py --list-only
```

### Check Environment

```bash
python run_all_experiments.py --check-env
```

## Data Module

The `DataModule` class (`modules/data_module.py`) handles:

- Loading CSV datasets with embedded metadata (feature types and actions)
- Stratified K-fold cross-validation (5 folds)
- Preprocessing: MinMax scaling for numerical features, label encoding for categorical features
- Missing value handling (sentinel values -9, -8, -7 mapped to NaN and dropped)

Feature types in the CSV metadata row:
- `N` = Numerical (continuous)
- `D` = Discrete (integer)
- `B` = Binary (0/1)
- `C` = Categorical (string, label-encoded)

Feature actions in the CSV metadata row:
- `ANY` = Can be changed freely
- `FIX` = Immutable (cannot be changed in counterfactuals)
- `PREDICT` = Label column
